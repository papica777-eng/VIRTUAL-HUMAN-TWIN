## 🚀 Getting Started (Showcase Runner)

To boot up the presentation layer locally on your machine and experience the aesthetics firsthand:

### 1. Prerequisites
- Node.js `v20.x` or higher
- `npm` or `bun` installed on your machine.

### 2. Installation
```bash
# Clone the showcase repository
git clone https://github.com/papica777-eng/qantum-aeterna.github.io.git
cd qantum-aeterna.github.io

# Navigate to the dashboard workspace
cd apps/dashboard

# Install required UI dependencies
npm install
```

### 3. Ignite the Dashboard
```bash
npm run dev
```
Navigate to [http://localhost:3000](http://localhost:3000) to view the Glassmorphism Showcase.
